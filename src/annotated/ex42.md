The [_Signorini problem_](https://en.wikipedia.org/wiki/Signorini_problem) is a classical elastostatic contact problem that models the equilibrium of an elastic body resting on a rigid, frictionless surface. Under applied forces, the body deforms while being constrained to not penetrate the obstacle.

Mathematically, the problem can be formulated as the minimization of the total potential energy functional:

$$
J(v) = \frac{1}{2} \int_\Omega (C \, \epsilon(v) : \epsilon(v)) \, dx
- \int_\Omega f \cdot v \, dx,
$$

over the feasible set
$$
K = \\{ v \in H^1(\Omega, \mathbb{R}^3) \;|\; v|_{\Gamma_D} = g \text{ and } v \cdot \widetilde{n} \leq \phi \text{ on } \Gamma_C \\}.
$$

Here, $\epsilon(v)$ is the symmetric gradient of the displacement field $v$, $C$ is the symmetric positive-definite elasticity tensor, and $f$ is the body force. The boundary is partitioned into the contact boundary $\Gamma_C$ and the Dirichlet boundary $\Gamma_D$. The function $\phi$ denotes the prescribed gap function on $\Gamma_C$, representing the distance between the inital body position and the rigid plane. Correspondingly, $\widetilde{n}$ is the ourward normal associated with the gap function.

For simplicity, we assume homogeneous Dirichlet boundary conditions ($g=0$) in the formulation below.

To solve this problem, we discretize the problem using the [Proximal Gakerkins Method](
https://doi.org/10.48550/arXiv.2307.12444) introduced by Keith and Surowiec. Here, the minization problem becomes a saddle point formulation.
At each iteration $k$, given two conforming finite element subspaces $V_h \subset V$ and $W_h \subset L^{\infty}(\Gamma_C)$ we solve for $(u_h^k,\psi_h^k)$ such that

<div>
$$
\begin{aligned}
\alpha_k (C\varepsilon(u_h^k),\varepsilon(v_h))
+ (\psi_h^k,v_h\cdot\widetilde{n})_{\Gamma_C}
&=
\alpha_k(f,v_h)
+ (\psi_h^{k-1},v_h\cdot\widetilde{n})_{\Gamma_C}
\\
(u_h^k\cdot\widetilde{n},w_h)_{\Gamma_C}
+ (\exp(-\psi_h^k),w_h)_{\Gamma_C}
&=
(\phi,w_h)_{\Gamma_C}
\end{aligned}
$$
</div>

for all $(v_h,w_h) \in V_h \times W_h$.

The system above is nonlinear due to the term $\exp(-\psi_h^k)$. To solve it, we apply Newton’s method. We introduce an increment $\delta \psi_h$ and linearize the system around the current iterate $\psi_h^k$. At each Newton iteration m, we solve for $(u_h^{k,m}, \delta \psi_h^{k,m})$ such that

<div>
$$
\begin{aligned}
\alpha_k (C\varepsilon(u_h^{k,m}),\varepsilon(v_h))
+ (\delta \psi_h^{k,m}, v_h \cdot \widetilde{n})_{\Gamma_C}
&=
\alpha_k (f,v_h)
+ (\psi_h^{k-1} - \psi_h^{k,m-1}, v_h \cdot \widetilde{n})_{\Gamma_C}
\\
(u_h^{k,m} \cdot \widetilde{n}, w_h)_{\Gamma_C}
- (\delta \psi_h^{k,m} \, \exp(-\psi_h^{k,m-1}), w_h)_{\Gamma_C}
&=
(\phi - \exp(-\psi_h^{k,m-1}), w_h)_{\Gamma_C}
\end{aligned}
$$
</div>
for all $(v_h,w_h) \in V_h \times W_h$.

After solving this system, the latent variable is updated as $\psi_h^{k,m} = \psi_h^{k,m-1} + \delta \psi_h^{k,m}$. The Newton iteration is repeated until a prescribed tolerance is satisfied. Once convergence is achieved, the algorithm proceeds to the next outer iteration of the Proximal Galerkin method.

### <i class="fa fa-check-square-o"></i>&nbsp; Annotated Example 42


[Example 42]() implements the finite element solver described above for the Signorini problem. The method is tested on a simple wheel structure mesh, where the entire outer cylindrical surface is treated as the contact boundary $\Gamma_C$.

The rigid surface plane is modeled as a horizontal plane located at $z = -0.1$, lying below the body. The gap function is defined as the vertical distance between the surface and a point on the boundary, i.e., $\phi(x,y,z) = z - (-0.1)$, and $\widetilde{n} = (0, 0, -1)$. This imposes the non-penetration constraint $u \cdot \widetilde{n} \leq \phi$.

Next (lines [78-85]()), the mesh is uniformly refined according to the specified refinement level, and its curvature is elevated to match the finite element order:

for (int l = 0; l < ref_levels; l++)

Finally, in lines [102-107](), the contact boundary is identified and extracted. For this example, boundary attribute 1 corresponds to the contact boundary $\Gamma_T$. A submesh is then constructed from this boundary, which will be used to define latent variables $\psi$.

```c++
Array<int> contact_attr(1);

```

#### Defining Variables and Spaces

In this section, we define the finite element spaces used for the discretization. Since the formulation involves variables defined on different domains, we construct separate spaces for the volume and the contact boundary.

The displacement field $u$ is defined in the volume $\Omega$ and is approximated using a vector-valued $H^1$ space. The latent variable $\psi$ is defined only on the contact boundary $\Gamma_T$ and is approximated using an $L^2$ space on the submesh.

In the default configuration (`order = 1`), we use a higher-order space for the displacement and a lower-order space for the boundary variable:


```c++
H1_FECollection H1fec(order+1, dim);
FiniteElementSpace H1fes(&mesh, &H1fec, dim);

L2_FECollection L2fec(order-1, sub_dim);
FiniteElementSpace L2fes(&contact_mesh, &L2fec, 1);
```

To represent the mixed system, we use a block structure that combines the volume and boundary unknowns. In MFEM, this is handled using a `BlockVector`. In lines [110-117](), we define offsets based on the number of degrees of freedom (DOFs) in each space:

```c++
Array<int> offsets(3);
offsets[0] = 0;
offsets[1] = H1fes.GetVSize();
offsets[2] = L2fes.GetVSize();
offsets.PartialSum();

BlockVector x(offsets), rhs(offsets);
x = 0.0; rhs = 0.0;
```

#### Essential Boundary Conditions

This block of code identifies the essential degrees of freedom for the displacement field and stores them in a list of true DOFs. These DOFs will later be eliminated from the linear system.


```c++
Array<int> ess_bdr_x(mesh.bdr_attributes.Max());
Array<int> ess_bdr_y(mesh.bdr_attributes.Max());

ess_bdr_x = 0; ess_bdr_x[1] = 1; ess_bdr_x[2] = 1;
ess_bdr_y = 0; ess_bdr_y[1] = 1; ess_bdr_y[2] = 1;

Array<int> ess_tdof_list, tmp;
H1fes.GetEssentialTrueDofs(ess_bdr_x, tmp, 0); ess_tdof_list.Append(tmp);
H1fes.GetEssentialTrueDofs(ess_bdr_y, tmp, 1); ess_tdof_list.Append(tmp);
```

Here, essential boundary conditions are applied separately to each component of the vector-valued displacement field. The third argument of the `GetEssentialTrueDofs` function (0 and 1) specifies the vector component (e.g., $x$ and $y$ directions).

Next, we construct a marker array that flags the essential DOFs:

```c++
col_markers.SetSize(H1fes.GetTrueVSize());
col_markers = 0;
for (int i=0; i<ess_tdof_list.Size(); i++)
{
    col_markers[ess_tdof_list[i]] = 1;
}
```

This marker is used later when assembling the bilinear forms, to eliminate contributions associated with essential DOFs.

#### Initializing Coefficients and Solution

In this section, we define the coefficients and initialize the solution vectors used in the solver.

First, we define the body force and the contact normal vector. The force is applied in the negative $z$-direction, and the contact normal is chosen as $\widetilde{n} = (0, 0, -1)$:

```c++
Vector f(dim);
f = 0.0; f(dim-1) = -0.1;

Vector n_tilde(dim);
n_tilde = 0.0; n_tilde(dim-1) = -1.0;

VectorConstantCoefficient f_coeff(f);
VectorConstantCoefficient n_tilde_c(n_tilde);
```

Next, we define an initial guess for the displacement. Codes in lines [370-377]() defines the calcultions of an initial guess. It is a resonable guess for the configuration where the body drops by $−0.1$ and reaches the contact surface, which is where contact begins to occur.

```c++
void InitialGuess(const Vector &x, Vector &u)
{
   const int dim = x.Size();
   const real_t disp = -0.1;

   u = 0.0;
   u(dim-1) = disp;
}
```

Finally, the initial guess is projected onto the finite element space:

```c++
VectorFunctionCoefficient init_u_c(dim, InitialGuess);
u_gf.ProjectCoefficient(init_u_c);
u_old_gf = u_gf;
```

For the latent variable defined on the contact boundary, we need to compute an initial value of $\psi$ based on the current displacement $u$. This requires evaluating $\psi = -\ln(\phi - u \cdot \widetilde{n})$ on $\Gamma_C$.

To do this, we first construct a temporary $H^1$ space on the submesh and transfer the $u_gf$ onto the contact boundary. The gap function $\phi$ is then evaluated pointwise, and the initial value of $\psi$ is computed using the expression above.

The resulting values are then projected onto the boundary finite element space for $\psi$, providing the initial guess for the displacement solution.

```c++
H1_FECollection *trace_fec; FiniteElementSpace *trace_fes;
trace_fec = new H1_FECollection(order+1, sub_dim);
trace_fes = new FiniteElementSpace(&contact_mesh, trace_fec, dim);

GridFunction u_trace_gf(trace_fes);
contact_mesh.Transfer(u_gf, u_trace_gf);

FunctionCoefficient gap_cf(GapFunction);
LogarithmGridFunctionCoefficient psi_init_cf(u_trace_gf, gap_cf, n_tilde);
psi_gf.ProjectCoefficient(psi_init_cf);
psi_old_gf = psi_gf;

delete trace_fec;
delete trace_fes;
```

The code in lines [347-359]() defines how the coefficient for $\psi$ is evaluated at each quadrature point. To ensure numerical stability, the evaluated value is bounded from above. 

```c++
real_t LogarithmGridFunctionCoefficient::Eval(ElementTransformation &T,
                                              const IntegrationPoint &ip)
{
   MFEM_ASSERT(u != NULL, "grid function is not set");
   const int dim = T.GetSpaceDim();

   Vector u_val(dim);
   u->GetVectorValue(T, ip, u_val);

   // Return -ln(ϕ₁ - u · ñ)
   real_t val = -log(gap->Eval(T, ip) - u_val * *n_tilde);
   return min(max_val, val);
}
```

#### Bilinear Forms

The bilinear form in this block system has the structure
$$
\begin{bmatrix}
K & M^T \\\\
M & -H
\end{bmatrix}
$$

To represent this system in MFEM, a `BlockOperator` is defined to store the individual matrix blocks. Each bilinear term is assembled separately and then inserted into the corresponding position in the block operator.

##### Diagonal Blocks

The diagonal blocks correspond to operators defined independently on the volume and boundary finite element spaces. In particular, the block `A00` represents the elasticity term <span>$\alpha_k (C\varepsilon(u_h^{k,m}),\varepsilon(v_h))$</span>. This block is constructed using a standard bilinear form on the volume mesh. After assembly, essential boundary conditions are eliminated.

```c++
BilinearForm a00(&H1fes);
a00.AddDomainIntegrator(new ElasticityIntegrator(one, lambda, mu));
a00.Assemble();
a00.Finalize();
SparseMatrix &A00 = a00.SpMat();
A00.EliminateBC(ess_tdof_list, mfem::Operator::DIAG_ONE);
```

Lines [260-265]() constructs the block `A11`, which represents the term $-(\delta \psi_h^{k,m} \, \exp(-\psi_h^{k,m-1}), w_h)_{\Gamma_C}$. This bilinear form is reconstructed and assembled every iteration, as $\exp(-\psi_h^{k,m-1})$ gets updated every iteration.

```c++
BilinearForm a11(&L2fes);
a11.AddDomainIntegrator(new MassIntegrator(exp_psi));
a11.Assemble();
a11.Finalize();
SparseMatrix &A11 = a11.SpMat();
A11 *= -1.0;
```

##### Off-Diagonal Blocks

The core of this example is the construction of a mixed system that simultaneously solves for variables defined on different meshes. This leads to mixed coupling terms involving finite element spaces defined on different domains.

In particular, some bilinear and linear forms must couple variables from the $H^1(\Omega)$ space and the $L^2(\Gamma_T)$ space. Since MFEM’s standard `MixedBilinearForm` requires both spaces to be defined on the same mesh, a custom mixed bilinear form is introduced to handle this coupling. The code in lines [47-327]() in [ex42.hpp]() defines the structure of the custom mixed bilinear form used to assemble the off-diagonal coupling term $(u \cdot \widetilde{n}, w)_{\Gamma_T}$, where $u \in H^1(\Omega)$ and $w \in L^2(\Gamma_T)$. 

To achieve this, the first step is to take the trial FE space defined on the parent mesh and the test FE space defined on the submesh, and construct the corresponding trace space by restricting the parent space to the contact boundary.

```c++
auto *parent_fec = trial_parent_fes->FEColl();
parent_trace_fec.reset(parent_fec->GetTraceCollection());
```

Using the trace space, a mapping between the DOFs on the submesh and the parent mesh is constructed using MFEM’s `BuildVdofToVdofMap()` utility. This mapping identifies how each DOF on the boundary corresponds to a DOF in the volume mesh. We then construct the matrix representation of this mapping by assigning 1s at the corresponding $(i,j)$ entries, if $j = map(i)$.
```c++
parent_trace_fes = std::make_unique<FiniteElementSpace>(
                    sub_mesh, parent_trace_fec.get(),
                    trial_parent_fes->GetVDim());

SubMeshUtils::BuildVdofToVdofMap(*parent_trace_fes, *trial_parent_fes_,
                                sub_mesh->GetFrom(),
                                sub_mesh->GetParentElementIDMap(),
                                sub_to_parent);

sub_bf = std::make_unique<MixedBilinearForm>(parent_trace_fes.get(),
                                            test_sub_fes);

const int ndof_sub = parent_trace_fes->GetVSize();
const int ndof_parent = trial_parent_fes_->GetVSize();

R = std::make_unique<SparseMatrix>(ndof_sub, ndof_parent);
for (int i = 0; i < ndof_sub; i++)
{
    int I = sub_to_parent[i];
    if (I >= 0) { R->Add(i, I, 1.0); }
}
R->Finalize();
```

A standard `MixedBilinearForm` is then defined on the submesh using the trail trace FES and test FES. During assembly, the mixed bilinear form is first assembled on the submesh, and the transformation matrix is subsequently applied to arrive at the desired bilinear form maxtrix. This produces the tight coupling operator between the volume and boundary variables.

```c++
virtual void Finalize()
{
...
    sub_bf->Finalize();
...
    mat.reset(mfem::Mult(sub_bf->SpMat(), *R));
    mat->Finalize();
}

```

The block `A10` corresponds to the coupling term <span>$(u_h^{k,m} \cdot \widetilde{n}, w_h)_{\Gamma_C}$</span>, and is assembled using the custom mixed bilinear form described above. 
Since the displacement variable is subject to essential boundary conditions, the corresponding columns are removed from the assembled matrix. 
The block `A01` is obtained as the transpose of `A10`. The code in lines [193-200]() constructs the two off-diagonal terms.


```c++
ParentToSubMixedBilinearForm a10(&H1fes, &L2fes);
a10.AddBoundaryDomainIntegrator(new MixedFormIntegrator(n_tilde_c, dim));
a10.Assemble();
a10.Finalize();
SparseMatrix &A10 = a10.SpMat();
A10.EliminateCols(col_markers);

SparseMatrix *A01 = Transpose(A10);
```

After each term is constructed, they are inserted into a `BlockOperator` to form the full mixed system. At each iteration, the penalty parameter $\alpha_k$ is updated, and the corresponding scaling is applied to the elasticity block.

```c++
BlockOperator A(offsets);
A.SetBlock(0,0,&A00);
A.SetBlock(1,0,&A10);
A.SetBlock(0,1,A01);
...
A.SetBlockCoef(0,0,alpha);
A.SetBlock(1,1,&A11);
```

#### Linear Forms

For the linear form <span>$\alpha_k (f,v_h) + (\psi_h^{k-1} - \psi_h^{k,m-1}, v_h \cdot \widetilde{n})_{\Gamma_C}$</span>, we first obtain the force term by integrating the force coefficient over the volume. 

At each iteration, the scaling parameter $\alpha_k$ is applied to the force term. The second term is assembled by applying the transpose coupling operator to the contact boundary grid functions, which transfers their contribution into the parent linear form. The full procedure is shown in lines [182-184]() and lines [253-255]() within the loops:

```c++ 
LinearForm b_force(&H1fes);
b_force.AddDomainIntegrator(new VectorDomainLFIntegrator(f_coeff));
b_force.Assemble();
...
b0.Set(alpha, b_force);
A01->AddMult(psi_old_gf, b0, 1.0);
A01->AddMult(psi_gf, b0, -1.0);
```

The linear form $(\phi - \exp(-\psi_h^{k,m-1}), w_h)_{\Gamma_C}$ is assembled on the contact boundary by evaluating the coefficient $\phi - \exp(-\psi_h)$ pointwise and applying it within the boundary integrator.

```c++
SumCoefficient gap_minus_exp_psi(gap_cf, exp_psi, 1.0, -1.0);
...
b1.AddDomainIntegrator(new DomainLFIntegrator(gap_minus_exp_psi));
b1.Assemble();
```

#### Preconditioner and Solving the Linear System

After assigning the assembled bilinear and linear forms into the block system, a preconditioner is applied to improve the efficiency of the linear solver. In this example, we use a Schur complement-based preconditioner. For the mixed system, the preconditioner has the form

$$
P =
\begin{bmatrix}
\mathrm{diag}(\alpha_k K) & 0 \\\\
0 & - H - M \, \mathrm{diag}(\alpha_k K)^{-1} M^T
\end{bmatrix}.
$$

To construct this preconditioner, the two diagonal blocks are assembled separately as shown in lines [273-291]().

```c++
Vector A00_diag(A00_diag_base);
A00_diag *= alpha;
SparseMatrix KinvMt(*A01);
for (int i=0; i<A00_diag.Size(); i++)
{
KinvMt.ScaleRow(i, 1.0/A00_diag(i));
}
SparseMatrix *MKinvMt = Mult(A10, KinvMt);
SparseMatrix *S = Add(-1.0, A11, -1.0, *MKinvMt);

DSmoother P00(A00);
ScaledOperator P00_scaled(&P00, 1.0 / alpha);
GSSmoother P11(*S);
P00.iterative_mode = false;
P11.iterative_mode = false;

BlockDiagonalPreconditioner prec(offsets);
prec.SetDiagonalBlock(0, &P00_scaled);
prec.SetDiagonalBlock(1, &P11);
```

Each diagonal block is then approximated using suitable smoothers, and combined into a `BlockDiagonalPreconditioner`. This results in an efficient preconditioner that captures the coupling structure of the system while remaining inexpensive to apply.

At last, the Linear sytem $AX=B$ is solved using a GMRES solver.

```c++
GMRESSolver gmres;
gmres.SetRelTol(1e-8);
gmres.SetKDim(500);
gmres.SetPrintLevel(0);
gmres.SetMaxIter(100000);
gmres.SetPreconditioner(prec);
gmres.SetOperator(A);
gmres.Mult(rhs, x);
```
